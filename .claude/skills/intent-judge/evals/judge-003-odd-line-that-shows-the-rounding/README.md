# An odd third line shows the rounding and is not an extra

B1's test gains a third line of 101 pence. 10% off is 90.9, which rounds down to 90, so the line is what shows "rounded down to the penny". The test is right.

The judge should report nothing.

Tricky because the odd amount looks like something the scenario never asked for, and a judge that reads the setup loosely may call it an added requirement, or miss that it is the rounding.
