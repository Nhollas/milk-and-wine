# The earliest two, from a list in no order

B1's test lists three members in neither join order nor the order of the expected offers, and expects the 2 who joined earliest, earliest first. The list's order, the join order and the ID order all differ, so the one assertion shows who is chosen, in what order, and that the third gets nothing. The test is right.

The judge should report nothing.

Every requirement is in plain sight. It's here to catch a judge that splits the scenario finely and then can't find a separate assertion for each part.
