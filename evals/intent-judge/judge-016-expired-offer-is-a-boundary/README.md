# Offering again after an offer expires is the boundary

B6 says a member holding an offer "that hasn't expired" is skipped. Its second test offers a place to a member whose offer has expired. The scenario doesn't say that in so many words, but it is where "hasn't expired" stops applying. The tests are right.

The judge should report nothing.

Tricky because the second test's Given is the opposite of the scenario's, so a judge may call it an added requirement, or a contradiction.
